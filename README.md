# Ещё одна поездка

Самостоятельный статический сайт. Не импортирует файлы Card Generator и не использует его инфраструктуру.

Локальный запуск: `python3 -m http.server 4179 --bind 127.0.0.1 --directory dist`.
Все файлы для хостинга находятся в `dist/`. Сборка и npm-зависимости не нужны.

Музыка запускается после нажатия «Открыть нашу историю» или кнопки звука. Кнопка звука доступна при прокрутке. Браузер может запретить автоматический запуск до первого взаимодействия.

Все 8 исходных фотографий и MP3 скопированы без изменений. Чёрно-белое фото повёрнуто в отображении CSS. Голосовая заметка не расшифрована и не опубликована; текст основан на сообщении пользователя.

Проверки: `node --check dist/app.js`; браузерная проверка 320/390/768/1440 px, загрузки изображений, воспроизведения/паузы музыки, дождя/солнца и клавиатурного фокуса.
